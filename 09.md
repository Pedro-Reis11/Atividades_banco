# Exercícios — Projeto Empresa

## Inserção de Filial

### Comando

```sql
INSERT INTO Filial (cnpj, nome, endereco)
VALUES (
    '20202020000120',
    'Filial Savassi',
    'Rua Pernambuco, 400 - Belo Horizonte/MG'
);
```

### O INSERT cria um registro com o mesmo telefone da filial central (valor padrão/default do campo telefone)?

**Resposta:** Não.

O comando retornará erro **1062 (Duplicate Entry)** porque já existe uma filial cadastrada com o CNPJ `20202020000120`, que é a chave primária da tabela.

Exemplo do erro:

```text
ERROR 1062 (23000): Duplicate entry '20202020000120' for key 'PRIMARY'
```

Portanto, o erro não ocorre por causa do telefone, mas porque o CNPJ já existe na tabela.

## Apresente os itens do estoque com validade posterior a '2026-09-30' e anterior a '2027-01-15'

### Consultando diretamente o estoque

```sql
SELECT *
FROM Estoque
WHERE validade > '2026-09-30'
  AND validade < '2027-01-15';
```

### Ou utilizando BETWEEN

```sql
SELECT *
FROM Estoque
WHERE validade BETWEEN '2026-10-01' AND '2027-01-14';
```

# Tabela Promoção

## Relacionamento correto

Cada promoção pertence a um único item do estoque.

Relacionamento:

```text
Estoque (1) -------- (N) Promoção
```

A tabela `Promocao` deve possuir uma chave estrangeira apontando para o item de estoque.

---

## Criação da tabela Promoção

```sql
CREATE TABLE Promocao (
    id INT AUTO_INCREMENT,
    id_produto INT NOT NULL,
    cnpj_filial VARCHAR(14) NOT NULL,
    data_inicio DATE NOT NULL,
    data_fim DATE NOT NULL,
    preco_custo DECIMAL(10,2) NOT NULL,
    preco_promocional DECIMAL(10,2) NOT NULL,

    PRIMARY KEY (id),

    CONSTRAINT fk_promocao_estoque
        FOREIGN KEY (id_produto, cnpj_filial)
        REFERENCES Estoque(id_produto, cnpj_filial),

    CONSTRAINT check_periodo
        CHECK (data_fim >= data_inicio),

    CONSTRAINT check_preco
        CHECK (preco_promocional >= preco_custo)
);
```

# Tabela Funcionario

## Criação da tabela

```sql
CREATE TABLE Funcionario (
    cpf VARCHAR(11) NOT NULL,
    nome VARCHAR(200) NOT NULL,
    data_nascimento DATE NOT NULL,
    data_contratacao DATE NOT NULL,
    endereco VARCHAR(200),
    telefone VARCHAR(15),
    cargo VARCHAR(100) NOT NULL,
    salario DECIMAL(10,2) NOT NULL,

    cnpj_filial VARCHAR(14) NOT NULL,
    cpf_supervisor VARCHAR(11),

    PRIMARY KEY (cpf),

    FOREIGN KEY (cnpj_filial)
        REFERENCES Filial(cnpj),

    FOREIGN KEY (cpf_supervisor)
        REFERENCES Funcionario(cpf)
);
```
