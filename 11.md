# Exercício 1 - Joins Básicos (Banco Empresa)

## Consulta 1 - Fornecedores que possuem produtos cadastrados

```sql
SELECT f.nome AS fornecedor,
       p.nome AS produto
FROM Fornecedor f
INNER JOIN Produto p
    ON f.cnpj = p.cnpj_fornecedor;
```

## Consulta 2 - Todos os fornecedores, com ou sem produto

```sql
SELECT f.nome AS fornecedor,
       p.nome AS produto
FROM Fornecedor f
LEFT JOIN Produto p
    ON f.cnpj = p.cnpj_fornecedor;
```

## Consulta 3 - Todos os produtos, com ou sem fornecedor

```sql
SELECT f.nome AS fornecedor,
       p.nome AS produto
FROM Fornecedor f
RIGHT JOIN Produto p
    ON f.cnpj = p.cnpj_fornecedor;
```

## Consulta 4 - Fornecedores sem nenhum produto cadastrado

```sql
SELECT f.nome AS fornecedor,
       f.cnpj,
       p.nome AS produto
FROM Fornecedor f
LEFT JOIN Produto p
    ON f.cnpj = p.cnpj_fornecedor
WHERE p.cnpj_fornecedor IS NULL;
```

## Consulta 5 - Fornecedores, produtos e identificação dos produtos

```sql
SELECT f.nome AS fornecedor,
       p.id,
       p.nome AS produto
FROM Fornecedor f
INNER JOIN Produto p
    ON f.cnpj = p.cnpj_fornecedor;
```

# Exercício 2 - Joins com Filtros e Ordenação (Banco Empresa)

## Consulta 1 - Produtos com preço acima de R$ 50,00 e seu fornecedor

```sql
SELECT e.preco,
       p.nome AS produto,
       f.nome AS fornecedor
FROM Estoque e
INNER JOIN Produto p
    ON e.id_produto = p.id
INNER JOIN Fornecedor f
    ON p.cnpj_fornecedor = f.cnpj
WHERE e.preco > 50
ORDER BY f.nome, p.nome;
```

## Consulta 2 - Fornecedores com nome iniciado em "A" e seus produtos

```sql
SELECT f.nome AS fornecedor,
       p.nome AS produto
FROM Fornecedor f
INNER JOIN Produto p
    ON f.cnpj = p.cnpj_fornecedor
WHERE f.nome LIKE 'A%'
ORDER BY f.nome, p.nome;
```

## Consulta 3 - Fornecedores e produtos em ordem decrescente por fornecedor

```sql
SELECT f.nome AS fornecedor,
       p.nome AS produto
FROM Fornecedor f
LEFT JOIN Produto p
    ON f.cnpj = p.cnpj_fornecedor
ORDER BY f.nome DESC;
```

## Consulta 4 - Produtos com preço entre R$ 20,00 e R$ 100,00

```sql
SELECT f.nome AS fornecedor,
       p.nome AS produto,
       e.preco
FROM Fornecedor f
INNER JOIN Produto p
    ON f.cnpj = p.cnpj_fornecedor
INNER JOIN Estoque e
    ON e.id_produto = p.id
WHERE e.preco BETWEEN 20 AND 100;
```

## Consulta 5 - Fornecedores, produtos, estoque e filiais (incluindo fornecedores sem produto)

```sql
SELECT p.nome AS produto,
       f.nome AS fornecedor,
       e.quantidade,
       Filial.nome AS filial
FROM Estoque e
INNER JOIN Produto p
    ON e.id_produto = p.id
RIGHT JOIN Fornecedor f
    ON p.cnpj_fornecedor = f.cnpj
LEFT JOIN Filial
    ON e.cnpj_filial = Filial.cnpj;
```

## Consulta 1 - Todos os clientes e seus pedidos, incluindo quem nunca pediu

```sql
SELECT c.nome AS cliente,
       p.id_pedido,
       p.data_pedido,
       p.total

    ON p.id_cliente = c.id_cliente;
```

```sql
SELECT c.nome AS cliente,
       p.id_pedido,
       p.total

    ON c.id_cliente = p.id_cliente;
```

## Consulta 3 - Produtos de cada pedido com quantidade e valor total do item

```sql
SELECT pe.id_pedido,
       p.nome AS produto,
       ip.quantidade,
       p.preco AS preco_unitario,
       p.preco * ip.quantidade AS total_item
FROM Pedido pe
INNER JOIN ItemPedido ip
    ON pe.id_pedido = ip.id_pedido
INNER JOIN Produto p
    ON ip.id_produto = p.id_produto
ORDER BY pe.id_pedido, p.nome;
```

## Consulta 4 - Clientes que nunca fizeram pedido

```sql
SELECT c.id_cliente,
       c.nome AS cliente
FROM Cliente c
LEFT JOIN Pedido p
    ON p.id_cliente = c.id_cliente
WHERE p.id_pedido IS NULL;
```

## Consulta 5 - Pedidos com valor acima de R$ 80,00

```sql
SELECT c.nome AS cliente,
       p.id_pedido,
       p.total
FROM Cliente c
INNER JOIN Pedido p
    ON p.id_cliente = c.id_cliente
WHERE p.total > 80;
```

## Consulta 1 - Todos os clientes e suas reservas, incluindo clientes sem reservas

```sql
SELECT c.nome AS cliente,
       r.id_reserva,
       r.data_viagem,
       r.valor
FROM Cliente c
LEFT JOIN Reserva r
    ON r.id_cliente = c.id_cliente;
```

## Consulta 2 - Cada reserva com o nome do cliente e o nome do destino

```sql
SELECT r.id_reserva,
       c.nome AS cliente,
       d.nome_destino AS destino,
       r.data_viagem,
       r.valor
FROM Reserva r
INNER JOIN Cliente c
    ON c.id_cliente = r.id_cliente
INNER JOIN Destino d
    ON d.id_destino = r.id_destino;
```

## Consulta 3 - Destinos que ainda não receberam reserva

```sql
SELECT d.id_destino,
       d.nome_destino,
       d.pais
FROM Destino d
LEFT JOIN Reserva r
    ON r.id_destino = d.id_destino
WHERE r.id_reserva IS NULL;
```

## Consulta 4 - Clientes que ainda não fizeram reserva

```sql
SELECT c.id_cliente,
       c.nome AS cliente
FROM Cliente c
LEFT JOIN Reserva r
    ON r.id_cliente = c.id_cliente
WHERE r.id_reserva IS NULL;
```

## Consulta 5 - Todos os clientes e destinos, com ou sem reserva

O MySQL não tem `FULL JOIN`, então o resultado é a união de dois `LEFT JOIN`.

```sql
SELECT c.nome AS cliente,
       d.nome_destino AS destino,
       r.id_reserva,
       r.valor
FROM Cliente c
LEFT JOIN Reserva r
    ON r.id_cliente = c.id_cliente
LEFT JOIN Destino d
    ON d.id_destino = r.id_destino

UNION

SELECT c.nome,
       d.nome_destino,
       r.id_reserva,
       r.valor
FROM Destino d
LEFT JOIN Reserva r
    ON r.id_destino = d.id_destino
LEFT JOIN Cliente c
    ON c.id_cliente = r.id_cliente;
```

# Exercício 5 - Banco de Dados Farmácia

## Criação e carga do banco

A coluna `Compra.id_fornecedor` aceita `NULL` para representar compras sem fornecedor registrado.

```sql
CREATE DATABASE IF NOT EXISTS farmacia;
USE farmacia;

);

CREATE TABLE Fornecedor (
    id_fornecedor INT PRIMARY KEY,
    nome          VARCHAR(100) NOT NULL,

CREATE TABLE Compra (
    id_compra      INT PRIMARY KEY,
```

## Consulta 1 - Medicamentos com o fornecedor, incluindo os sem compra registrada

```sql
SELECT m.nome AS medicamento,
       f.nome AS fornecedor
FROM Medicamento m
LEFT JOIN Compra c
    ON c.id_medicamento = m.id_medicamento
LEFT JOIN Fornecedor f
    ON f.id_fornecedor = c.id_fornecedor;
```

## Consulta 2 - Medicamentos sem fornecedor que foram comprados

```sql
SELECT DISTINCT m.nome AS medicamento
FROM Medicamento m
INNER JOIN Compra c
    ON c.id_medicamento = m.id_medicamento
LEFT JOIN Fornecedor f
    ON f.id_fornecedor = c.id_fornecedor
WHERE f.id_fornecedor IS NULL;
```

## Consulta 3 - Com fornecedor e que ainda não foram comprados

Medicamento e fornecedor só se relacionam pela tabela `Compra`. Por isso, esta consulta lista os fornecedores cadastrados que não têm nenhuma compra.

```sql
SELECT f.id_fornecedor,
       f.nome AS fornecedor
FROM Fornecedor f
LEFT JOIN Compra c
    ON c.id_fornecedor = f.id_fornecedor
WHERE c.id_compra IS NULL;
```

## Consulta 4 - Medicamentos sem fornecedor que ainda não foram comprados

```sql
SELECT m.id_medicamento,
       m.nome AS medicamento
FROM Medicamento m
LEFT JOIN Compra c
    ON c.id_medicamento = m.id_medicamento
WHERE c.id_compra IS NULL;
```

## Consulta 5 - Todos os dados de compras, medicamentos e fornecedores

Emulação de `FULL JOIN` com `UNION`, para trazer registros com ou sem fornecedor e com ou sem compra.

```sql
SELECT c.id_compra, c.quantidade, c.data_compra,
       m.id_medicamento, m.nome AS medicamento, m.preco, m.validade, m.laboratorio,
       f.id_fornecedor, f.nome AS fornecedor, f.cidade
FROM Medicamento m
LEFT JOIN Compra c
    ON c.id_medicamento = m.id_medicamento
LEFT JOIN Fornecedor f
    ON f.id_fornecedor = c.id_fornecedor

UNION

SELECT c.id_compra, c.quantidade, c.data_compra,
       m.id_medicamento, m.nome, m.preco, m.validade, m.laboratorio,
       f.id_fornecedor, f.nome, f.cidade
FROM Fornecedor f
LEFT JOIN Compra c
    ON c.id_fornecedor = f.id_fornecedor
LEFT JOIN Medicamento m
    ON m.id_medicamento = c.id_medicamento;
```
