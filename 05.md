# Exercício 1 - Banco de Dados Aviação

## Consulta 1 - Partida de Belo Horizonte

```sql
SELECT *
FROM Voo
WHERE cidade_partida = 'Belo Horizonte';
```

## Consulta 2 - Destino Fortaleza

```sql
SELECT *
FROM Voo
WHERE cidade_destino = 'Fortaleza';
```

## Consulta 3 - Viagem de volta agendada

```sql
SELECT *
FROM Voo
WHERE volta IS NOT NULL;
```

## Consulta 4 - Valor abaixo de R$ 950,00

```sql
SELECT *
FROM Voo
WHERE valor < 950.00;
```

## Consulta 5 - Valor acima de R$ 1.200,00

```sql
SELECT *
FROM Voo
WHERE valor > 1200.00;
```

## Consulta 6 - Valor entre R$ 500,00 e R$ 800,00

```sql
SELECT *
FROM Voo
WHERE valor BETWEEN 500.00 AND 800.00;
```

## Consulta 7 - Partida agendada para 2027

```sql
SELECT *
FROM Voo
WHERE YEAR(ida) = 2027;
```

## Consulta 8 - Volta agendada para 2028

```sql
SELECT *
FROM Voo
WHERE YEAR(volta) = 2028;
```

## Consulta 9 - Partida de Cuiabá e destino Curitiba

```sql
SELECT *
FROM Voo
WHERE cidade_partida = 'Cuiabá'
AND cidade_destino = 'Curitiba';
```

## Consulta 10 - Partida de Minas Gerais

```sql
SELECT *
FROM Voo
WHERE estado_partida = 'MG';
```

## Consulta 11 - Destino Rio Grande do Sul

```sql
SELECT *
FROM Voo
WHERE estado_destino = 'RS';
```

## Consulta 12 - Partida de Tocantins ou do Pará

```sql
SELECT *
FROM Voo
WHERE estado_partida IN ('TO', 'PA');
```

## Consulta 13 - Destino Salvador ou Aracaju

```sql
SELECT *
FROM Voo
WHERE cidade_destino IN ('Salvador', 'Aracaju');
```

## Consulta 14 - Viagem de volta não agendada

```sql
SELECT *
FROM Voo
WHERE volta IS NULL;
```

## Consulta 15 - Substring "es" na cidade/estado de partida

```sql
SELECT *
FROM Voo
WHERE cidade_partida LIKE '%es%'
OR estado_partida LIKE '%es%';
```

## Consulta 16 - Substring "ta" na cidade/estado de destino

```sql
SELECT *
FROM Voo
WHERE cidade_destino LIKE '%ta%'
OR estado_destino LIKE '%ta%';
```

## Consulta 17 - Substring "or" na cidade/estado de partida ou de destino

```sql
SELECT *
FROM Voo
WHERE cidade_partida LIKE '%or%'
OR estado_partida LIKE '%or%'
OR cidade_destino LIKE '%or%'
OR estado_destino LIKE '%or%';
```

# Exercício 2 - Banco de Dados Hotelaria

## Consulta 1 - Cidade de Minas Gerais

```sql
SELECT *
FROM Hotel
WHERE estado = 'MG';
```

## Consulta 2 - Valor da diária abaixo de R$ 300,00

```sql
SELECT *
FROM Hotel
WHERE valor_diaria < 300.00;
```

## Consulta 3 - Cidade São Luís

```sql
SELECT *
FROM Hotel
WHERE cidade = 'São Luís';
```

## Consulta 4 - Categoria 3 estrelas

```sql
SELECT *
FROM Hotel
WHERE categoria = 3;
```

## Consulta 5 - Substring "resort" no nome do hotel

```sql
SELECT *
FROM Hotel
WHERE nome LIKE '%resort%';
```

## Consulta 6 - Cidade Recife ou Salvador

```sql
SELECT *
FROM Hotel
WHERE cidade IN ('Recife', 'Salvador');
```

## Consulta 7 - Tipo de acomodação "Quarto duplo"

```sql
SELECT *
FROM Hotel
WHERE acomodacao = 'Quarto duplo';
```

## Consulta 8 - Valor da diária acima de R$ 100,00

```sql
SELECT *
FROM Hotel
WHERE valor_diaria > 100.00;
```

## Consulta 9 - Substring "elite" no nome do hotel ou da acomodação

```sql
SELECT *
FROM Hotel
WHERE nome LIKE '%elite%'
OR acomodacao LIKE '%elite%';
```

## Consulta 10 - Hotel com check-in agendado para 2027

```sql
SELECT *
FROM Hotel
WHERE YEAR(checkin) = 2027;
```

## Consulta 11 - Cidade Curitiba e acomodação tipo "Suite"

```sql
SELECT *
FROM Hotel
WHERE cidade = 'Curitiba'
AND acomodacao = 'Suite';
```

## Consulta 12 - Estado Rio Grande do Sul

```sql
SELECT *
FROM Hotel
WHERE estado = 'RS';
```

## Consulta 13 - Estado São Paulo ou Paraná

```sql
SELECT *
FROM Hotel
WHERE estado IN ('SP', 'PR');
```

## Consulta 14 - Hospedagem sem café incluso

```sql
SELECT *
FROM Hotel
WHERE cafe_incluso = FALSE;
```

## Consulta 15 - Substring "standard" no tipo da acomodação

```sql
SELECT *
FROM Hotel
WHERE acomodacao LIKE '%standard%';
```

## Consulta 16 - Valor da diária entre R$ 250,00 e R$ 450,00

```sql
SELECT *
FROM Hotel
WHERE valor_diaria BETWEEN 250.00 AND 450.00;
```

## Consulta 17 - Hotel com check-out agendado para 2028

```sql
SELECT *
FROM Hotel
WHERE YEAR(checkout) = 2028;
```

## Consulta 18 - Garagem inclusa na hospedagem

```sql
SELECT *
FROM Hotel
WHERE garagem_inclusa = TRUE;
```

## Consulta 19 - Garagem inclusa, mas sem café incluso

```sql
SELECT *
FROM Hotel
WHERE garagem_inclusa = TRUE
AND cafe_incluso = FALSE;
```

## Consulta 20 - Café incluso, mas sem garagem inclusa

```sql
SELECT *
FROM Hotel
WHERE cafe_incluso = TRUE
AND garagem_inclusa = FALSE;
```
