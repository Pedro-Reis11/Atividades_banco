# Respostas dos Exercícios SQL Update

## Exercício 1 — Produto

### a) Corrigir o nome do produto de id 1

```sql
UPDATE Produto
SET nome = 'Arroz Tipo 1 5kg'
WHERE id = 1;
```

---

### b) Adicionar prefixo "[Eletrônico]" aos produtos que contenham "usb-c"

```sql
UPDATE Produto
SET nome = CONCAT('[Eletrônico] ', nome)
WHERE nome LIKE '%usb-c%';
```

---

### c) Transferir os produtos 6 e 7 para outro fornecedor

```sql
UPDATE Produto
SET cnpj_fornecedor = '11111111000101'
WHERE id IN (6, 7);
```

---

### d) Concatenar identificação usando CASE WHEN

```sql
UPDATE Produto
SET nome =
    CASE
        WHEN id = 2 THEN CONCAT(nome, ' [Produto 2]')
        WHEN id = 3 THEN CONCAT(nome, ' [Produto 3]')
        WHEN id = 4 THEN CONCAT(nome, ' [Produto 4]')
        ELSE nome
    END
WHERE id IN (2, 3, 4);
```

---

### e) Explicação

Um `UPDATE` sem cláusula `WHERE` afetaria **todos os registros da tabela**.

Exemplo:

```sql
UPDATE Produto
SET cnpj_fornecedor = '11111111000101';
```

Nesse caso todos os produtos passariam a pertencer ao mesmo fornecedor, destruindo o relacionamento correto entre produtos e fornecedores e comprometendo a integridade dos dados.

# Exercício 2 — Pedido

### a) Atualizar pedido 3 para "pronto"

```sql
UPDATE Pedido
SET status = 'pronto'
WHERE id = 3;
```

---

### b) Adicionar observação aos pedidos pendentes da cliente Ana Souza

```sql
UPDATE Pedido
SET observacao = 'cliente vai retirar às 18h'
WHERE cliente = 'Ana Souza'
  AND status = 'pendente';
```

---

### c) Avançar status usando CASE WHEN

```sql
UPDATE Pedido
SET status =
    CASE
        WHEN status = 'preparando' THEN 'pronto'
        WHEN status = 'pronto' THEN 'entregue'
        ELSE status
    END;
```

---

### d) Atualizar observação usando subquery

```sql
UPDATE Pedido
SET observacao = CONCAT(
        COALESCE(observacao, ''),
        ' - pedido grande'
    )
WHERE id IN (
    SELECT id
    FROM (
        SELECT id
        FROM Pedido
        WHERE quantidade > 10
    ) AS pedidos_grandes
);
```

---

# Exercício 3 — Pacote

### a) Desativar pacote sem vagas

```sql
UPDATE Pacote
SET ativo = FALSE
WHERE destino = 'Bonito - MS'
  AND vagas = 0;
```

---

### b) Reajuste de 10%

```sql
UPDATE Pacote
SET preco = preco * 1.10
WHERE vagas > 10;
```

---

### c) Promoção de 15% para RS e PR

```sql
UPDATE Pacote
SET preco = preco * 0.85
WHERE destino LIKE '%RS%'
   OR destino LIKE '%PR%';
```

---

### d) Reduzir uma vaga do pacote mais barato

```sql
UPDATE Pacote
SET vagas = vagas - 1
ORDER BY preco ASC
LIMIT 1;
```

---

### e) Explicação

Se um funcionário executar:

```sql
UPDATE Pacote
SET preco = preco * 0.85;
```

sem `WHERE`, todos os pacotes receberão desconto, inclusive aqueles que não participam da promoção. Isso pode gerar prejuízo financeiro e necessidade de correções manuais.

# Exercício 4 — Conta

### a) Depósito de R$ 500,00

```sql
UPDATE Conta
SET saldo = saldo + 500.00
WHERE numero = 1004;
```

---

### b) Preencher telefones nulos

```sql
UPDATE Conta
SET telefone = '0800-000-0000'
WHERE telefone IS NULL;
```

---

### c) Aplicar rendimento de 0,5%

```sql
UPDATE Conta
SET saldo = saldo * 1.005
WHERE tipo = 'poupanca'
  AND saldo > 5000.00;
```

---

### d) Classificar contas com saldo negativo

#### Inserindo dados de teste

```sql
INSERT INTO Conta
(numero, titular, saldo, tipo, telefone)
VALUES
(1006, 'Cliente Teste', -100.00, 'corrente', NULL);
```

#### Atualização

```sql
UPDATE Conta
SET telefone =
    CASE
        WHEN tipo = 'corrente'
             AND saldo < 0
        THEN 'CONTATO URGENTE'
        ELSE telefone
    END;
```

---

### e) Reflexão

Atualizações diretas em saldo são extremamente sensíveis. Um erro pode alterar valores financeiros de milhares de clientes, gerar inconsistências contábeis e prejuízos financeiros. Em sistemas bancários, normalmente são utilizadas transações, auditoria e mecanismos de validação antes da confirmação.

# Exercício 5 — Filial e Estoque

### a) Aplicar desconto de 30%

```sql
UPDATE Estoque
SET preco = preco * 0.70
WHERE id_produto = 5
  AND cnpj_filial = '20202020000120';
```

---

### b) Zerar estoque de produtos vencidos

```sql
UPDATE Estoque
SET quantidade = 0
WHERE validade < '2026-11-01';
```

---

### c) Adicionar 10 unidades ao produto 1

```sql
UPDATE Estoque
SET quantidade = quantidade + 10
WHERE id_produto = 1;
```

---

### d) Aumentar preço em 5% usando subquery

```sql
UPDATE Estoque
SET preco = preco * 1.05
WHERE cnpj_filial IN (
    SELECT cnpj
    FROM (
        SELECT cnpj
        FROM Filial
        WHERE nome = 'Filial Centro'
    ) AS filial_centro
);
```

---

### e) Explicação

A chave primária composta:

```text
(id_produto, cnpj_filial)
```

garante que um mesmo produto possa existir em várias filiais, mas apenas uma vez em cada filial.

Exemplo válido:

| id_produto | cnpj_filial |
|------------|-------------|
| 1 | 10101010000110 |
| 1 | 20202020000120 |

Ao atualizar um único registro é recomendado utilizar os dois campos da chave:

```sql
UPDATE Estoque
SET preco = 25.00
WHERE id_produto = 1
  AND cnpj_filial = '10101010000110';
```

Se utilizar apenas:

```sql
WHERE id_produto = 1
```

todos os estoques desse produto em todas as filiais poderão ser alterados.
```
