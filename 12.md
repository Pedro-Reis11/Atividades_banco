## Consulta 1 - Produtos e quantidade de filiais em que estão disponíveis

```sql
SELECT p.nome AS produto,
       COUNT(*) AS quantidade_filiais
FROM Produto p
JOIN Estoque e
    ON p.id = e.id_produto
GROUP BY p.id, p.nome
HAVING COUNT(*) >= 1;
```

## Consulta 2 - Produtos com mais de 100 unidades em estoque somando todas as filiais

```sql
SELECT p.nome AS produto,
       SUM(e.quantidade) AS quantidade_total
FROM Produto p
JOIN Estoque e
    ON p.id = e.id_produto
GROUP BY p.id, p.nome
HAVING SUM(e.quantidade) > 100;
```

## Consulta 3 - Preço médio de cada produto entre as filiais, do maior para o menor

```sql
SELECT p.nome AS produto,
       ROUND(AVG(e.preco), 2) AS preco_medio
FROM Produto p
JOIN Estoque e
    ON p.id = e.id_produto
GROUP BY p.id, p.nome
ORDER BY preco_medio DESC;
```

## Consulta 4 - Produtos cuja diferença entre maior e menor preço é maior que R$ 20,00

```sql
SELECT p.nome AS produto,
       MAX(e.preco) AS maior_preco,
       MIN(e.preco) AS menor_preco
FROM Produto p
JOIN Estoque e
    ON p.id = e.id_produto
GROUP BY p.id, p.nome
HAVING MAX(e.preco) - MIN(e.preco) > 20.00;
```

## Consulta 5 - Filiais com mais de 500 unidades em estoque

```sql
SELECT f.nome AS filial,
       SUM(e.quantidade) AS estoque_total
FROM Filial f
JOIN Estoque e
    ON f.cnpj = e.cnpj_filial
GROUP BY f.cnpj, f.nome
HAVING SUM(e.quantidade) > 500;
```

## Consulta 6 - Produtos disponíveis em pelo menos três filiais

```sql
SELECT p.nome AS produto,
       COUNT(*) AS quantidade_filiais
FROM Produto p
JOIN Estoque e
    ON p.id = e.id_produto
GROUP BY p.id, p.nome
HAVING COUNT(*) >= 3;
```
