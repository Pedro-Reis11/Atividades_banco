# Respostas dos Exercícios - Tabela Fornecedor

## Exercício 1 (Inserção e Restrições)

```sql
INSERT INTO Fornecedor (nome, telefone, endereco)
VALUES (
    'Suprimentos Globais',
    '(11) 91111-2222',
    'Av. das Nações, 500 - São Paulo, SP'
);
```

### O que acontece se executar novamente?

Se a tabela possuir uma restrição `UNIQUE` em alguma coluna (como nome ou telefone), o banco retornará erro de duplicidade e o registro não será inserido.

Caso não exista nenhuma restrição de unicidade, um novo registro será criado normalmente, recebendo um novo valor de `id`.

## Exercício 4 (Ordenação por Posição)

Considerando a estrutura:

1. id
2. nome
3. telefone
4. endereco

```sql
SELECT *
FROM Fornecedor
ORDER BY 2 DESC;
```

## Exercício 11 (Filtro de Texto Parcial - LIKE)

```sql

FROM Fornecedor
WHERE endereco LIKE '%SP';
```

Alternativa mais abrangente:

```sql

FROM Fornecedor
WHERE endereco LIKE '%SP%';
```
