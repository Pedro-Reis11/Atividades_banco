
# Respostas — Agregações, DISTINCT e Subqueries

## 1. Quantos fornecedores estão cadastrados?

```sql
SELECT COUNT(*) AS total_fornecedores
FROM Fornecedor;
```

---

## 2. Quantos produtos estão cadastrados?

```sql
SELECT COUNT(*) AS total_produtos
FROM Produto;
```

---

## 3. Quantas unidades existem em estoque?

```sql
SELECT SUM(quantidade) AS total_unidades
FROM Estoque;
```

---

## 4. Qual é o preço médio dos itens em estoque?

```sql
SELECT AVG(preco) AS preco_medio
FROM Estoque;
```

---

## 5. Qual é o maior preço registrado?

```sql
SELECT MAX(preco) AS maior_preco
FROM Estoque;
```

---

## 6. Qual é o menor preço registrado?

```sql
SELECT MIN(preco) AS menor_preco
FROM Estoque;
```

---

## 7. Qual é o valor total em estoque?

```sql
SELECT SUM(preco * quantidade) AS valor_total_estoque
FROM Estoque;
```

---

## 8. Quantos itens possuem validade anterior a 2027-01-01?

```sql
SELECT COUNT(*) AS total_itens_vencimento
FROM Estoque
WHERE validade < '2027-01-01';
```

---

## 9. Quais filiais possuem estoque?

```sql
SELECT DISTINCT cnpj_filial
FROM Estoque;
```

---

## 10. Quais produtos possuem estoque?

```sql
SELECT DISTINCT id_produto
FROM Estoque;
```

---

## 11. Quantos fornecedores diferentes possuem produtos cadastrados?

```sql
SELECT COUNT(DISTINCT cnpj_fornecedor) AS total_fornecedores
FROM Produto;
```

---

## 12. Quantas filiais diferentes vendem o produto de id = 1?

```sql
SELECT COUNT(DISTINCT cnpj_filial) AS total_filiais
FROM Estoque
WHERE id_produto = 1;
```

---

## 13. Soma da quantidade em estoque do produto 'Suco de Laranja 1L'

```sql
SELECT SUM(quantidade) AS quantidade_total
FROM Estoque
WHERE id_produto = (
    SELECT id
    FROM Produto
    WHERE nome = 'Suco de Laranja 1L'
);
```

---

## 14. Preço médio do produto 'Fone de Ouvido Bluetooth'

```sql
SELECT AVG(preco) AS preco_medio
FROM Estoque
WHERE id_produto = (
    SELECT id
    FROM Produto
    WHERE nome = 'Fone de Ouvido Bluetooth'
);
```

---

## 15. Quantas filiais vendem 'Refrigerante Cola 2L'?

```sql
SELECT COUNT(DISTINCT cnpj_filial) AS total_filiais
FROM Estoque
WHERE id_produto = (
    SELECT id
    FROM Produto
    WHERE nome = 'Refrigerante Cola 2L'
);
```

---

## 16. Produtos que não aparecem no estoque

```sql
SELECT nome
FROM Produto
WHERE id NOT IN (
    SELECT id_produto
    FROM Estoque
);
```

---

## 17. Fornecedores sem produtos cadastrados

```sql
SELECT nome
FROM Fornecedor
WHERE cnpj NOT IN (
    SELECT cnpj_fornecedor
    FROM Produto
);
```

---

## 18. Produto e filial com a maior quantidade em estoque

```sql
SELECT id_produto, cnpj_filial
FROM Estoque
WHERE quantidade = (
    SELECT MAX(quantidade)
    FROM Estoque
);
```

---

## 19. Menor preço vendido pela Filial Savassi

```sql
SELECT MIN(preco) AS menor_preco
FROM Estoque
WHERE cnpj_filial = (
    SELECT cnpj
    FROM Filial
    WHERE nome = 'Filial Savassi'
);
```

---

## 20. Produtos cuja observação contém a palavra 'garantia'

```sql
SELECT nome
FROM Produto
WHERE id IN (
    SELECT id_produto
    FROM Identificacao
    WHERE observacao LIKE '%garantia%'
);
```
