# Respostas — Operadores, Funções e Expressões (Banco Empresa)

---

## 1. Valor do estoque (preço × quantidade) mais taxa fixa de embalagem de R$ 25,00

```sql
SELECT id_produto,
       cnpj_filial,
       preco,
       quantidade,
       preco * quantidade AS valor_estoque,
       preco * quantidade + 25.00 AS valor_com_embalagem
FROM Estoque;
```

A taxa é somada ao valor de cada item do estoque. Para uma taxa única sobre o total geral, use `SELECT SUM(preco * quantidade) + 25.00 FROM Estoque;`.

---

## 2. Imposto de 15% sobre o preço unitário somado ao próprio preço

```sql
SELECT id_produto,
       cnpj_filial,
       preco,
       preco * 0.15 AS imposto,
       preco + preco * 0.15 AS preco_com_imposto
FROM Estoque;
```

`preco + preco * 0.15` é o mesmo que `preco * 1.15`. A multiplicação é resolvida antes da soma.

---

## 3. Endereço seguido de duas barras e do nome do fornecedor (`CONCAT_WS`)

```sql
SELECT CONCAT_WS(' // ', endereco, nome) AS endereco_e_nome
FROM Fornecedor;
```

O primeiro argumento é o separador (` // `), inserido entre `endereco` e `nome`. Se algum valor for `NULL`, o `CONCAT_WS` o ignora, ao contrário do `CONCAT`, que retornaria `NULL`.

---

## 4. Produtos que vencem em exatamente 30 dias a partir de '2026-10-29' (`DATE_ADD`)

```sql
SELECT p.nome AS produto,
       e.cnpj_filial,
       e.validade
FROM Produto p
JOIN Estoque e
    ON e.id_produto = p.id
WHERE e.validade = DATE_ADD('2026-10-29', INTERVAL 30 DAY);
```

`DATE_ADD('2026-10-29', INTERVAL 30 DAY)` resulta em `2026-11-28`.

---

## 5. Fornecedores cujo nome termina com `Ltda.`

```sql
SELECT *
FROM Fornecedor
WHERE nome LIKE '%Ltda.';
```

O `%` no início aceita qualquer quantidade de caracteres antes de `Ltda.`. No `LIKE`, o ponto é um caractere comum, sem significado especial. Nomes escritos como `Ltda` (sem o ponto final) não são retornados.

---

## 6. Fornecedores com endereço começando com `Rua` e que não terminam em Belo Horizonte

```sql
SELECT *
FROM Fornecedor
WHERE endereco LIKE 'Rua%'
  AND endereco NOT LIKE '%Belo Horizonte%';
```

Como o endereço termina com a cidade, excluir quem contém `Belo Horizonte` deixa só os que terminam em outra cidade.

---

## 7. Localizar o caractere literal `%` no nome dos produtos (`ESCAPE`)

```sql
SELECT *
FROM Produto
WHERE nome LIKE '%!%%' ESCAPE '!';
```

Leitura do padrão `'%!%%'`:

- o primeiro `%` é curinga (qualquer texto antes);
- `!%` é o `%` literal, pois o `!` foi declarado como caractere de escape;
- o último `%` é curinga (qualquer texto depois).

---

## 8. Fornecedores cujo CNPJ não está associado a nenhum produto

```sql
SELECT f.cnpj,
       f.nome AS fornecedor
FROM Fornecedor f
LEFT JOIN Produto p
    ON p.cnpj_fornecedor = f.cnpj
WHERE p.id IS NULL;
```

O `LEFT JOIN` mantém todos os fornecedores, e o filtro `p.id IS NULL` deixa só os que não encontraram produto.

---

## 9. Preço até 12 ou validade posterior a '2026-12-31', somente com quantidade diferente de zero

```sql
SELECT *
FROM Estoque
WHERE (preco <= 12 OR validade > '2026-12-31')
  AND quantidade <> 0;
```

Os parênteses são necessários porque o `AND` tem precedência sobre o `OR`. Sem eles, o filtro `quantidade <> 0` valeria só para a segunda condição do `OR`.

---

## 10. Produtos com o CNPJ e o nome de suas filiais, ordenados por CNPJ e nome do produto

```sql
SELECT f.cnpj AS cnpj_filial,
       f.nome AS filial,
       p.nome AS produto
FROM Produto p
JOIN Estoque e
    ON e.id_produto = p.id
JOIN Filial f
    ON f.cnpj = e.cnpj_filial
ORDER BY f.cnpj ASC, p.nome ASC;
```

---

## 11. Nome do produto em maiúsculas e a quantidade de caracteres

```sql
SELECT UPPER(nome) AS nome_maiusculo,
       CHAR_LENGTH(UPPER(nome)) AS quantidade_caracteres
FROM Produto;
```

`CHAR_LENGTH` conta caracteres. O `LENGTH` conta bytes e retornaria valores maiores em nomes com acento.

---

## 12. Posição da primeira vogal `a` no nome, pesquisando a partir da quarta posição

```sql
SELECT nome,
       LOCATE('a', nome, 4) AS posicao_a
FROM Produto;
```

O terceiro argumento do `LOCATE` é a posição inicial da busca. O resultado é `0` quando não há `a` a partir da quarta posição.

---

## 13. Trocar `carioca` por `especial` e combinar com as cinco primeiras letras

```sql
SELECT nome,
       CONCAT(REPLACE(nome, 'carioca', 'especial'), ' - ', LEFT(nome, 5)) AS nome_modificado
FROM Produto;
```

O `REPLACE` faz a troca, o `LEFT(nome, 5)` extrai as cinco primeiras letras do nome original, e o `CONCAT` junta tudo.

---

## 14. Remover os espaços laterais de `' Produtos em promoção '` e mostrar ao lado do original

```sql
SELECT ' Produtos em promoção ' AS original,
       TRIM(' Produtos em promoção ') AS sem_espacos;
```

Para enxergar os espaços no resultado, é possível colocar colchetes em volta: `CONCAT('[', ' Produtos em promoção ', ']')` contra `CONCAT('[', TRIM(' Produtos em promoção '), ']')`.

---

## 15. Arredondar 1234,567 para duas casas, para a unidade e para a centena

```sql
SELECT ROUND(1234.567, 2)  AS duas_casas,
       ROUND(1234.567, 0)  AS unidade,
       ROUND(1234.567, -2) AS centena;
```

| duas_casas | unidade | centena |
|---|---|---|
| 1234.57 | 1235 | 1200 |

Um segundo argumento negativo arredonda as casas à esquerda da vírgula.

## 16. Teto e piso de 19,01 e sinal de -24, 0 e 150

```sql
SELECT CEIL(19.01)  AS teto,
       FLOOR(19.01) AS piso,
       SIGN(-24)    AS sinal_menos_24,
       SIGN(0)      AS sinal_zero,
       SIGN(150)    AS sinal_150;
```

| teto | piso | sinal_menos_24 | sinal_zero | sinal_150 |
|---|---|---|---|---|
| 20 | 19 | -1 | 0 | 1 |

## 17. Classificar o estoque por quantidade: Esgotado, Baixa, Normal ou Alta

```sql
SELECT id_produto,
       cnpj_filial,
       quantidade,
       CASE
           WHEN quantidade = 0  THEN 'Esgotado'
           WHEN quantidade <= 20 THEN 'Baixa'
           WHEN quantidade <= 50 THEN 'Normal'
           ELSE 'Alta'
       END AS situacao_estoque
FROM Estoque;
```

O `CASE` avalia os `WHEN` na ordem e para no primeiro verdadeiro. Por isso `quantidade <= 20` só atinge valores maiores que zero.

---

## 18. Classificar o prazo de validade comparando com '2026-10-29'

```sql
SELECT id_produto,
       cnpj_filial,
       validade,
       CASE
           WHEN validade < '2026-10-29' THEN 'Vencido'
           WHEN validade <= DATE_ADD('2026-10-29', INTERVAL 30 DAY) THEN 'Vence em breve'
           ELSE 'Prazo regular'
       END AS situacao_prazo
FROM Estoque;
```

O enunciado não define o que é "em breve". Adotei o mesmo intervalo de 30 dias da questão 4. Para outro prazo, troque o `30` do `INTERVAL`.

---

## 19. Desconto ausente substituído por 10% do preço e valor líquido

A tabela `Estoque` não tem coluna de desconto. Assumi uma coluna `desconto` (valor em reais, aceitando `NULL`). Se ela ainda não existir:

```sql
ALTER TABLE Estoque
ADD COLUMN desconto DECIMAL(10,2) NULL;
```

Consulta:

```sql
SELECT id_produto,
       cnpj_filial,
       preco,
       desconto,
       COALESCE(desconto, preco * 0.10) AS desconto_aplicado,
       preco - COALESCE(desconto, preco * 0.10) AS valor_liquido
FROM Estoque;
```

O `COALESCE` devolve o desconto cadastrado e, quando ele é `NULL`, usa 10% do preço.

## 20. Validade formatada como ano, mês/ano e dia da semana por extenso

```sql
SET lc_time_names = 'pt_BR';

SELECT validade,
       DATE_FORMAT(validade, '%Y')    AS ano,
       DATE_FORMAT(validade, '%m/%Y') AS mes_ano,
       DATE_FORMAT(validade, '%W')    AS dia_da_semana
FROM Estoque;
```

O `SET lc_time_names = 'pt_BR'` faz o `%W` retornar o dia em português (por exemplo, `sexta-feira`). Sem ele, o MySQL usa inglês (`Friday`).
